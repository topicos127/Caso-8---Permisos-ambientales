\# Sistema de Permisos Ambientales



Proyecto listo para correr localmente con Docker Compose.



\## Requisitos

\- Docker Desktop (con Docker Compose).

\- Git.



\## ¿Cómo iniciar el proyecto? (Para Nathaly y el equipo)

1\. Clonar el repositorio: `git clone https://github.com/NathalyB-Mcklean/Caso-8---Permisos-ambientales.git`

2\. Abrir una terminal en la carpeta del proyecto.

3\. Ejecutar el script de inicio: `.\\start.ps1`

4\. Abrir el navegador en `http://localhost:5000`



\## ¿Cómo bajar los cambios más recientes?

Si José o Abdiel suben cambios al repositorio, solo hay que hacer:

1\. `git pull`

2\. `docker compose up -d --build`
